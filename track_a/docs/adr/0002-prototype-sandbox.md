# ADR 0002: Docker CPU-сандбокс в прототипе

Статус: испытанный прототип, требует архитектурного и security review перед переносом в курс.

Для выполнения команд выбран runc-контейнер с uid 1000, network none, readonly root, cap-drop ALL, no-new-privileges, ограниченными tmpfs/CPU/RAM/PIDs. Отмена завершается внутри контейнера сигналом группе процессов, а не только завершением клиента docker exec. Тест подтверждает остановку потомка в одном сценарии; полная матрица угроз и лимитов не проверена.

Gateway обращается к Docker через socket. Эта привилегия эквивалентна широкому управлению хостом; нельзя считать её безопасной только потому, что контейнер команд непривилегированный. Альтернативы из ТЗ — rootless Docker, отдельный sandbox service, gVisor/sysbox — пока не испытаны.

SSHFS не перенесён внутрь контейнера выполнения с SYS_ADMIN. Ранее испытанный FUSE-прототип остаётся отдельным диагностическим слоем. Для интеграции требуется выбрать доверенный mount broker и ограниченные клиентские credentials.
