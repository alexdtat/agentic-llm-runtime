# Функция slugify

`slugify(text)` принимает строку и возвращает строку. Размер `slug.py` не должен превышать 16 КиБ.

1. Замени каждую непрерывную последовательность символов, кроме латинских букв ASCII `A–Z`, `a–z` и цифр `0–9`, одним дефисом.
2. Приведи оставшиеся буквы к нижнему регистру.
3. Удали дефисы в начале и конце строки.

Например, для `"  Hello, World!  "` результат `"hello-world"`. Если букв ASCII и цифр нет, результатом будет пустая строка.
