# Агрегация журнала

Утилита запускается как `python3 parse_logs.py PATH` и читает UTF-8 файл.
Каждая непустая строка содержит три поля, разделённые символом `|`:

```text
timestamp|level|message
```

Время имеет вид `YYYY-MM-DDTHH:MM:SSZ` или `YYYY-MM-DDTHH:MM:SS±HH:MM`.
Уровень — `INFO`, `WARN` или `ERROR`. Сообщение непустое и может содержать
`|`. Пустые строки и некорректные записи пропускаются. Строки журнала могут
идти в любом порядке.

Приведи каждую метку времени к UTC и округли вниз до начала часа. Выведи
в stdout один JSON-объект. Ключи часов имеют вид `YYYY-MM-DDTHH:00Z`.
Значение каждого ключа — объект с целыми полями `total` (все записи часа)
и `errors` (только ERROR, включая ноль). Часы без записей не выводятся.
Для пустого входа результат `{}`. Порядок ключей произвольный.
Используй стандартную библиотеку Python.
