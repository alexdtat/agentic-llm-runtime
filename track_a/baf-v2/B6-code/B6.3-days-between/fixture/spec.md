# Разность календарных дат

Функция `days_between(a, b)` из `days.py` принимает две строки.
Поддерживаются два формата: `YYYY-MM-DD` и `DD.MM.YYYY г.`
(между годом и `г.` один неразрывный пробел U+00A0).
В каждом формате цифры ASCII, месяц и день записаны двумя цифрами,
год четырьмя. По краям строки допускаются пробельные символы.

Возвращай целое число календарных суток от даты a до даты b: положительное,
если b позже, отрицательное, если раньше, и ноль для одной и той же даты.
Используй григорианский календарь и стандартную библиотеку Python.
Если хотя бы одна строка пуста после удаления пробелов или содержит
неправильный формат либо невозможную дату, возвращай `None`.

Пример: `days_between("31.03.2025 г.", "2025-04-02")` возвращает `2`.
