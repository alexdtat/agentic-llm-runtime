# Таблицы

Запишите каждый файл как YAML mapping из указанного имени в значение. Все ключи и значения должны оставаться строками при чтении YAML 1.1.

## countries.yaml

| Имя | Код |
| --- | --- |
| Norway | NO |
| Ontario | ON |
| Germany | DE |

ON — код региона в предоставленных данных. Сохраните исходные значения без исправлений.
