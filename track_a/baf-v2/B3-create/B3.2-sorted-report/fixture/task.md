# Таблица для отчёта

Создайте UTF-8 CSV с заголовком date,city,amount и разделителем запятая.
Даты привести к YYYY-MM-DD. Суммы сохранить с двумя знаками после точки.
Порядок по возрастанию даты, при равной дате сохранить исходный порядок.
