# Нормализация полуоткрытых диапазонов

`join_ranges(ranges)` получает список кортежей `(start, end)` из двух целых
чисел. Диапазон включает `start` и исключает `end`.

Если `start > end` хотя бы у одной пары, вызов должен завершиться
исключением `ValueError`. Пары с равными границами пропускаются.
Остальные пары объедини, если они перекрываются или соприкасаются.
Верни список кортежей `(start, end)`, отсортированный по началу.
Для пустого списка верни пустой список. Исходный список не изменяй.

Пример: `join_ranges([(4, 7), (3, 4), (10, 10)]) == [(3, 7)]`.

Используй только стандартную библиотеку Python. Вызов функции не требует
файлов, сети или вывода в терминал.
