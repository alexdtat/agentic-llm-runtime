# Реестр решений

Учитывай только пункты разделов «Принято» во всех протоколах из `meetings/`.
Каждый пункт этого раздела содержит полный текст решения и ответственного.
Дата решения — дата заседания, указанная в заголовке протокола.
Обсуждения, предложения, перенесённые вопросы и справки в реестр не входят.

Результат `decisions.json` — массив объектов с полями `decision`, `date`
(YYYY-MM-DD) и `owner`. Значения — строки. Сохраняй полные формулировки
решений и имена, без служебных меток и Markdown-разметки. Порядок записей
произвольный.
