# Отчёт отдела поддержки за февраль 2026

`data/north.csv` и `data/south.csv` — журналы двух групп, `data/corrections.csv`
содержит более свежие записи. Запись из corrections полностью заменяет запись
с тем же ID. Учитывай заявки с итоговым статусом closed и датой закрытия
с 2026-02-01 по 2026-02-28 включительно. Поле hours хранит целые трудозатраты
в часах. `data/targets.csv` содержит план, а не фактические заявки.

Сделай `report.md` с Markdown-таблицей из двух столбцов. В первом используй
следующие подписи, во втором запиши целые числа:

- Закрыто заявок
- Трудозатраты, ч
- Север, закрыто
- Юг, закрыто

Порядок строк и Markdown вокруг таблицы произвольные.
