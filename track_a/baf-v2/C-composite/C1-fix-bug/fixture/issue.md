# Пропадают заказы из последней неполной партии

При группировке заказов для отправки пять заказов и лимит в два заказа
дают две партии. Должны получаться партии из двух, двух и одного заказа
соответственно. Правило относится к `dispatch.plan_orders`; другие способы
группировки могут по назначению отбрасывать неполный хвост.

Сохрани исходный порядок, возвращай только непустые партии. Пустой список
даёт пустой план. Нулевой или отрицательный лимит по действующему контракту
вызывает ValueError даже для пустого списка. Исходные заказы не меняй.

Прогони `python3 -m unittest discover -s tests` после правки. Тесты и другие
входные файлы оставь в исходном виде.
