# Предложение для первой оценки ЧП2 · 19 ноября 2026

**Статус: на согласование.** Доступ к DeepSeek запрошен. Подтверждения ключа, разрешённого model ID, цены и успешного обращения к провайдеру пока нет. Этот документ не запускает оценку.

## Что считать одной попыткой

Первая пара — серверный `sequential-v2` с явно зафиксированной разрешённой версией DeepSeek Flash через ModelProxy. Вариант для согласования — DeepSeek 4.1 Flash, если такой точный ID и версия доступны на выданном endpoint и соответствуют §0-1 локального ТЗ. До прогона вписать доступный идентификатор, провайдера, индекс и дату проверки. Для финальной матрицы можно добавить (2) тот же харнес со второй допущенной моделью, затем (3) второй харнес с первой моделью. Выбор и реализация второй и третьей пар относятся к следующему этапу.

Одна попытка получает только пользовательскую формулировку и чистую копию её fixture. Для каждой попытки нужны отдельные ID и сессия, чистая история и артефакты. После terminal runner проверяет подтверждение остановки писателей и собирает итог **со стороны клиента**. Это важно: mounted collect сейчас собирает только имена успешных ReadFile/WriteFile и может пропустить файл, созданный через shell. Исполняемые ответы оцениваются в отдельном ограниченном grader без сети, ключей и доступа к другим попыткам. Скрытые проверки и эталоны остаются вне agent workspace.

## Правила исхода

- **Pass** — подтверждённая остановка писателей, успешный независимый checker и завершённая очистка.
- **Fail** — ответ неверен, результата нет по вине агента, нарушен контракт задачи или исчерпан зафиксированный бюджет модели/харнеса. Сохраняются причина и трасса.
- **Infra error** — недоступны провайдер, экспорт, grader или сбор результата, неизвестен исход операции либо не подтверждена очистка. Такой исход показывается отдельным числом. При незавершённой очистке следующие попытки останавливаются.
- Инфраструктурную ошибку не переигрывать автоматически. Новая согласованная попытка получает новый ID и ссылку на исходную. Сбой в реализации устраняется в новой версии; результаты разных версий публикуются отдельно.
- Отчёт показывает pass/fail/infra_error по задачам и повторам, число запланированных и завершённых попыток, время, токены и пропуски. Привести удачную и проблемную трассу. Офлайн-прогон с моделью-заглушкой относится к проверке инфраструктуры.

**До запуска** проверить сквозной путь реального runner и isolated grader на синтетической попытке, свежесть каждого экспорта, сохранность тестовых данных, покрытие всех 39 задач, наличие полных трасс до их удаления при close и работу бюджета. Утвердить первую пару, состав задач и лимит расходов. Для ЧП2 отдельно показать демонстрацию между двумя машинами.
